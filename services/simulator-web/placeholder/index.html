BedLight AI — 가상 침실 시뮬레이터

이 페이지는 컨테이너 구동 확인용 정적 안내 페이지입니다. 시뮬레이터 기능(침실·사람·조명 렌더링, WebSocket 연결, 조명 제어)은 아직 구현되지 않았습니다.

예정 기능

  • React + Vite 기반 침실 / 사람 / 조명 시뮬레이션
  • Controller WebSocket /ws/simulator/{room_id} 연결
  • LIGHT_OFF_REQUESTED 수신 → 조명 끄기 → LIGHT_OFF_APPLIED 반환
  • 화면 반영 시간(render_ms) 측정
